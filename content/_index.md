**Hi 👋 I'm Amita.** I'm a software engineer at Cloudera, working mostly on backend systems and large-scale software systems. I write about my experiences here, from design choices to day-to-day engineering.

A programmer at heart, I love building, learning, and breaking stuff through code 😬. To me, clean code has the same quiet joy as the fresh pages of a new book.

## A Bit About My Work

My father brought home a desktop when I was 10 - back then it was mostly a sophisticated toy for me. I've come a long way since, from using apps to building them.

I started my career as a Big Data Engineer, building applications that process data at scale. Since then, my work has expanded across backend engineering, cloud infrastructure, and distributed systems. I've been involved in building and evolving large-scale software systems using technologies like Java, Go, Scala, Hadoop, Spark, and Kafka.

I'm fascinated by how systems fit together, the trade-offs behind design decisions, and what makes software easier to evolve.

I've also explored NLP, frontend development, and a variety of programming languages including Python, R, JavaScript, Haskell, Groovy, C#, and C++. I have a soft spot for type-safe languages, but I like letting the problem choose the tool.

## About This Blog

This blog has evolved through several iterations, from Blogger to a Gatsby-powered setup that I maintained for years. Eventually, I switched to Hugo for its minimal, content-first approach. I wanted something that lets me focus on writing rather than keeping up with frameworks, dependencies, and build pipelines.

The blog is open source and lives on [GitHub](https://github.com/amita-shukla/blog-hugo). Feel free to explore, contribute, or fork it and make it your own.
